# Magnus for your website

Magnus answers visitors from public information you approve. It can help someone
understand your services and find a useful next step. Where request preparation
has been configured, a visitor can describe what they need, check an editable
draft and choose whether to send it.

Website chat is separate from your private Magnus conversations, files and work.
Installing it does not give visitors access to your workspace or turn their
questions into Tasks.

**Current availability:** assisted setup. Account access and service preparation
are arranged with the Magnus team. These guides do not announce unrestricted
signup, automatic billing or a Magnus plugin for every website platform.

You need a public HTTPS website, permission to configure it, and a way to publish
verification and installation tags in its delivered HTML. Your site can be
personal or commercial. You do not need to create a Project or set up private
work tools to start website setup.

The standard embed provides answers and links. Conversational request preparation
requires an additional reviewed form definition, privacy purpose and receiving
integration. It is not enabled just by pasting the embed.

Examples use fictional `.example` addresses. Use the exact verification tag and
installation code supplied for your own website.

Reviewed against the Magnus setup implementation on 12 November 2026. Your
assigned setup, allowance and accepted service terms govern your installation.
